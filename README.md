# Japan Post Stamp Bot

日本郵便の風景印情報を自動取得し、Notionデータベースに登録するボットです。

## 機能

- 日本郵便公式サイトから風景印詳細情報をスクレイピング
- 新着情報をNotionデータベースに自動登録
- 毎日 JST 8:00 / 12:00 / 22:00 に自動実行

## Notionデータベースプロパティ

| プロパティ | 型 | 内容 |
|---|---|---|
| 郵便局 | タイトル | 郵便局名 |
| 使用開始日 | 日付 | 風景印の使用開始日 |
| 意匠図案説明 | テキスト | 印面の図案説明 |
| 備考 | テキスト | 郵頀方法、窓口情報等 |
| 印面 | URL | 印面プレビュー画像のURL |
| 場所 | 場所 | 郵便局の住所（手動入力） |

> **注意**: `場所`（place型）はNotion公開APIでは書き込み不可のため、手動入力が必要です。

## ワークフロー

### 1. 定期実行（stamp_check.yml）

毎日自動実行され、前回確認時のID以降の新着情報をNotionに登録します。

| 実行時刻 | UTC cron |
|---|---|
| JST 8:00 | `0 23 * * *` |
| JST 12:00 | `0 3 * * *` |
| JST 22:00 | `0 13 * * *` |

### 2. 一括取り込み（bulk_import.yml）

IDの範囲を指定して過去の風景印情報を一括取り込みするワークフローです。
Actions → Bulk Import Fukeiin → Run workflow から実行。

| 入力項目 | 説明 | デフォルト |
|---|---|---|
| 開始ID | 取り込み開始ID | `1` |
| 終了ID | 取り込み終了ID | `1000` |
| リクエスト間隔(秒) | サーバ負荷軽減 | `2` |

**推奨の分割方法（間陠2秒、1回1000件 ≃ 33分）:**
```
1回目:     1 〜  1000
2回目:  1001 〜  2000
…
13回目: 12001 〜 12498
```

### 3. クリーンアップ（cleanup_notion.yml）

Notion内の全エントリを削除するワークフローです。不要なデータのリセット時に使用します。

## スクレイピング元

```
https://www.post.japanpost.jp/enjoy/culture/stamp/fuke/detail.php?id={ID}
```

IDは連番番号。存在しないIDは自動スキップされます。

## 必要なGitHub Secrets

| 名前 | 内容 |
|---|---|
| `NOTION_TOKEN` | Notionインテグレーショントークン |
| `NOTION_DATABASE_ID` | NotionデータベースID |

## 状態管理

`seen_stamps.json` に最後に確認したIDを保存します。次回の定期実行はこのIDの続きからチェックします。
